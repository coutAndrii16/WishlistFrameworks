У мене є частковий приклад проєкту на GitHub (посилання додаю). Потрібно проаналізувати його структуру, реалізацію API та стиль написання коду.
На основі прикладу виконай такі завдання (мають бути для symfony окремо та для laravel):

1. Реалізуй CRUD-операції для сутності:
   * GET (отримання даних)
   * POST (створення запису)
   * PATCH (часткове оновлення запису)
   * DELETE (видалення запису)
2. Дотримуйся архітектури, підходів та стилю кодування, які використовуються в прикладі проєкту.
3. Для кожного endpoint:
   * вкажи HTTP-метод;
   * маршрут (route);
   * приклад запиту;
   * приклад відповіді;
   * коди статусів HTTP;
   * короткий опис призначення.
4. На основі створених endpoint автоматично згенеруй документацію у форматі Postman Collection.
5. У результаті повинні бути створені дві окремі Postman Collection:
   * Symfony Collection;
   * Laravel Collection.
6. Надай готовий JSON для імпорту в Postman для кожної колекції.
Перед початком роботи проаналізуй структуру проєкту та поясни, як реалізовані існуючі API endpoints.
